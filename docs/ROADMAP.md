# Product Roadmap

## Phase 0 — Foundation

- Repository
- Expo app
- Supabase project
- Auth
- Database migrations
- RLS baseline
- Design system
- CI
- Sentry
- Analytics

## Phase 1 — Core Network

- Onboarding
- Profiles
- Home feed
- Posts
- Comments
- Reactions
- Follow users
- Search basics

### Exit criteria
A new student can join and participate in a useful conversation.

## Phase 2 — Knowledge Layer

- Questions
- Answers
- Accepted answer
- Solved state
- Topic tagging
- Related questions
- Question search

### Exit criteria
Students can reliably ask and resolve problems.

## Phase 3 — Communities

- Community creation
- Join/leave
- Community feed
- Community rules
- Moderation roles
- University/topic communities

### Exit criteria
Communities sustain recurring discussion.

## Phase 4 — Trust

- Alumni/professional labels
- Verification workflows
- Contribution reputation
- Better reporting
- Moderator dashboard

## Phase 5 — Networking

- Suggested people
- Experience-based discovery
- Alumni discovery
- Follow topics
- Better personalized feed

## Phase 6 — Mentorship

Only after strong organic usage:
- Mentor profiles
- Availability
- Booking
- Paid sessions
- Reviews
- Cancellation/refund policy

## Phase 7 — Institutions

- University pages
- Alumni networks
- Career centers
- Institution analytics
- Employer communities

## Explicitly postpone

- DMs
- Video-first content
- Job marketplace
- Complex AI recommendation system
- Ads
- Microservices
- Dedicated search cluster

until product usage justifies them.
