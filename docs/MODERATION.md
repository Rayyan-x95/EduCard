# Trust, Safety and Moderation

## Philosophy

EduCard is a global student community. Safety must be designed before scale.

## User controls

Every user should be able to:
- Report
- Block
- Mute where implemented
- Delete their own content
- Manage profile visibility
- Control notifications

## Report reasons

- Harassment
- Bullying
- Hate or discrimination
- Sexual content
- Threats
- Self-harm content
- Spam
- Scam/fraud
- Impersonation
- Misinformation
- Academic cheating
- Other

## Moderation states

Content:
- visible
- limited
- reported
- under_review
- removed

Account:
- active
- restricted
- suspended
- banned

## Moderation workflow

Report → automated triage → priority assignment → moderator review → action → audit log → appeal where applicable.

## Academic integrity

The platform should not become a cheating marketplace.

Educational help is allowed.

Requests that facilitate direct cheating during assessments should be handled according to platform policy and may be limited or redirected toward learning assistance.

## Verification

Possible V1 role labels:
- Student
- Alumni
- Professional
- Mentor

Verification should not imply endorsement of everything the person says.

## Anti-spam

Use:
- Rate limits
- Duplicate detection
- Account-age signals
- Report history
- Posting velocity
- Link restrictions for new accounts
- CAPTCHA/challenge mechanisms where necessary

## Moderator audit

Record:
- moderator
- action
- target
- reason
- timestamp
- previous state
- new state

Never make moderation decisions impossible to audit.
