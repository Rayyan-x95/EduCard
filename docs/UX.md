# UX and Screen Specification

## Navigation

Bottom tabs:

1. Home
2. Communities
3. Ask
4. Notifications
5. Profile

Search should be accessible globally from Home.

## Onboarding

### Screen 1
Welcome.

### Screen 2
Country/region.

### Screen 3
Education status.

Options:
- High school
- Undergraduate
- Postgraduate
- Vocational
- Graduate
- Other

### Screen 4
University/institution.

### Screen 5
Field of study.

### Screen 6
Interests/topics.

### Screen 7
Finish and enter feed.

Keep onboarding skippable where data is not essential.

## Home

Sections:
- Header/search
- Feed filter
- Question cards
- Discussion cards
- Suggested people
- Suggested communities

Primary CTA: Ask.

## Question detail

Display:
- Title
- Author context
- Body
- Topics
- Community
- Answer count
- Solved state
- Answers
- Answer composer
- Related questions

Make high-quality contributor context visible.

## Profile

Display:
- Avatar
- Name
- Role/status
- Education/work context
- Verification badges
- Bio
- Contributions
- Questions
- Answers
- Communities

## Community

Display:
- Header
- Description
- Rules
- Member count
- Feed
- About
- Join/leave

## Ask composer

Fields:
- Title
- Description
- Topics
- Community
- Optional image
- Post

Prompt:
"What are you trying to solve?"

## Visual principles

- Calm, academic, modern.
- Strong typography.
- High information density without feeling crowded.
- Avoid excessive gradients and gamification.
- Use badges as trust signals, not decoration.
- Prioritize content over vanity metrics.
- Accessibility target: WCAG-inspired contrast and touch targets.

## Empty states

Every empty state should explain:
1. What is empty.
2. Why it matters.
3. What the user can do next.

## Loading

Use skeletons for feed/question/profile content.

Avoid full-screen spinners for normal navigation.

## Error handling

Errors should:
- Explain what happened.
- Preserve user input where possible.
- Provide a recovery action.
